# BS Realty Design System

BS Realty Design System is the in-house component library built to standardize and accelerate
UI development across all BS Realty products — web, mobile, and insurance services.

All components are built from the official Figma designs and are shared across:
- `bsrealty-web-main`
- `insurance-web`
- `auth-service`

---

## Installation

The package is public on npm — install it exactly like any other package,
no login or token required:

```bash
npm install @bsrealtyllc/design-system
```

```tsx
import '@bsrealtyllc/design-system/style.css'; // once, e.g. in your app's root

import { BSRealtyButton } from '@bsrealtyllc/design-system';
import { BSRealtySearchbar } from '@bsrealtyllc/design-system';
import { BSRealtyTypography } from '@bsrealtyllc/design-system';
```

> Browse the sidebar for the full, always-up-to-date list of available components.
>
> Full publish/consume details (including CI setup) live in
> [`docs/DESIGN_SYSTEM_GUIDE.md`](https://github.com/bsr2023/storybook-bsrealtyllc-design/blob/main/docs/DESIGN_SYSTEM_GUIDE.md#6-publishing--consuming).

## Design Tokens

All components pull from a single CSS custom-property source,
[`src/tokens/tokens.css`](https://github.com/bsr2023/storybook-bsrealtyllc-design/blob/main/src/tokens/tokens.css).
Everything below renders live via `var(--bsr-*)`, so it can never drift from what components actually use —
if a token changes, this page updates with it.
