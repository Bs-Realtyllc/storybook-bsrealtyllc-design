# Foundations

The single source of truth for every color, type, and radius value below is
[`src/tokens/tokens.css`](https://github.com/bsr2023/storybook-bsrealtyllc-design/blob/main/src/tokens/tokens.css).
Components consume these as CSS variables (`var(--bsr-color-primary)`, etc.) —
**never hardcode a hex/rgba value in component CSS.** If you need a color or
size that isn't here, add a token instead.
